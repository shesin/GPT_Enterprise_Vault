Core Principles

1. Think broadly before implementation.
2. Architecture before implementation.
3. Build one excellent implementation before generalizing.
4. Evaluate tools before adopting them.
5. Free → Cheap → Paid progression unless ROI justifies otherwise.
6. Git is the permanent source of truth.
7. AI memory is a convenience, never the source of truth.
8. Every major feature begins with a written specification.
9. Independent review before every major commit.
10. Human makes the final decision.
11. Reusable assets over duplicate work.
12. Replace tools when evidence supports it, not because something is newer.
13. Simplicity beats unnecessary complexity.
14. Products over perfect infrastructure.
15. Benchmark AI using SMART Technology projects, not internet rankings.
16. Continuous learning and continuous improvement.
