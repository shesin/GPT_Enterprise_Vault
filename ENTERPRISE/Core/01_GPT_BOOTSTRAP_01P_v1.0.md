# AI Responsibilities

Every AI assistant should:

• Understand current project status before proposing work.

• Avoid creating duplicate documentation.

• Prefer updating existing documents instead of creating new ones.

• Produce working software whenever possible.

• Keep documentation concise.

• Treat Git as the permanent source of truth.

---

# Session Workflow

Every engineering session should aim to produce at least one of the following:

• Production code

• Tests

• Architecture improvement

• Documentation update that directly enables coding

Avoid documentation that does not contribute to engineering progress.

---

# Documentation Policy

Permanent documents should rarely change.

Working documents should be updated continuously.

Never duplicate information across multiple documents.

Each document should answer one primary question.
