## Summary

A strategic bead-based game project.

**Goal**

Design, test, and refine a fun, balanced, highly replayable strategy game with a reusable software architecture.

---

### SHARED

---

### VISION

Contains permanent engineering principles and AI workflow rules that apply across the entire repository.

## Repository Purpose

The GPT Enterprise Vault is the central workspace for building projects with a minimal, scalable structure.

Project Map files describe **what exists and why**.

GPT files describe **current work, decisions, experiments, and project status**.

VISION contains **permanent engineering principles** that guide every project.
